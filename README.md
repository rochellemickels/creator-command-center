# Creator Command Center

A calm, browser-based planning dashboard designed by Rochelle Mickels for creators building their brand, content, projects, and income streams.

## Live pages

- Main dashboard: `https://rochellemickels.github.io/creator-command-center/`
- Two-mode launch page: `https://rochellemickels.github.io/creator-command-center/launch.html`
- Guided tester and feedback page: `https://rochellemickels.github.io/creator-command-center/tester.html`

## Current features

- Rochelle's Owner Version
- New Creator Setup
- Today's Big 3
- Morning Brain Dump and archive
- Future Projects with platform tags
- Content idea bank and weekly content calendar
- Revenue tracking
- Weekly reflection and wins
- Local browser saving
- JSON backup and restore
- Beginner-friendly tester checklist and downloadable feedback

## Privacy

Dashboard entries are stored in the user's own browser with `localStorage`. Personal entries are not committed to this public repository. Different creators using different devices receive separate local data automatically.

## Hosting

This project is designed for free static hosting with GitHub Pages from the `main` branch and repository root.
