# Creator Command Center — Friendly Tester Guide

Use this short guide when a new creator tests the site for the first time.

## First-time setup

1. Open the published Creator Command Center link.
2. Choose **New Creator Setup**.
3. Enter your name, brand name, main platform, primary goal, and content niche.
4. Choose a theme and select **Create My Command Center**.

## What to test

- Add and complete the **Today’s Big 3**.
- Save a **Morning Brain Dump** entry.
- Add a **Future Project** and move it to the next stage.
- Add a content idea and move it through the content workflow.
- Add a course, resource link, and next learning step.
- Add a sample revenue entry.
- Complete a weekly review.
- Change the profile or theme.
- Export a backup and confirm that the download works.
- Open **Profile & Feedback** and save clear feedback about anything confusing.

## Important privacy note

The site stores each creator’s information in that person’s browser using local storage. Entries are not committed to GitHub and are not visible to other visitors. Data does not automatically sync between devices or browsers, so creators should use the Backup feature before switching devices or clearing browser data.

## Helpful feedback prompts

- What was the first thing you expected to do?
- Was any button or label confusing?
- Could you complete setup without help?
- Which section felt most useful?
- What felt unnecessary or overwhelming?
- What feature did you expect but could not find?
- Would you return to use this every day or every week?
